# Appointment Platform

İşletmelerin (berber, klinik, spor salonu) hizmet ve çalışma saatlerini yönettiği,
müşterilerin online randevu aldığı, yapay zekâ destekli bir randevu platformu.

**Durum:** Geliştirme aşamasında

## Planlanan teknolojiler
.NET 10, ASP.NET Core, EF Core, PostgreSQL, Redis, SignalR, Hangfire, React, Docker
